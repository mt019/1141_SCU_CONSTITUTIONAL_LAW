# 德國墮胎案一二中文全譯工程

本資料夾收納可獨立拆分成專案的翻譯工程文件。

## 內容

- `Schwangerschaftsabbruch I/原文與工程/`：BVerfGE 39, 1 的原文與中文全譯 LaTeX。
- `Schwangerschaftsabbruch II/原文與工程/`：BVerfGE 88, 203 的原文、抽取文字與中文全譯 LaTeX。
- `共用LaTeX/`：兩案共用的版面與 GG 條文腳註設定。
- `筆記與解析/`：翻譯或德文解析過程中的工作筆記。

## 編譯

兩份主檔分別為：

- `Schwangerschaftsabbruch I/原文與工程/BVerfGE_39_1_中文全譯.tex`
- `Schwangerschaftsabbruch II/原文與工程/BVerfGE_88_203_中文全譯.tex`

主檔已改為從 `../../共用LaTeX/` 載入共用檔，之後可整包移出作為獨立專案。
