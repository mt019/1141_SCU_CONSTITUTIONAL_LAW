# Glossar：德國墮胎案一、二德中術語與簡稱

版本日期：2026-06-01  
適用文件：BVerfGE 39, 1；BVerfGE 88, 203；導讀稿  

說明：本表以兩案現行譯文為準，供全文統一校對使用。`Indikation` 依本專案固定譯為「指標事由」；`Schwangerschaftsabbruch` 原則譯為「終止妊娠」；`Abtreibung` 依語境譯為「墮胎」。`Land/Länder` 在德國聯邦制語境中譯為「邦／各邦」，不用「州」。

## 十二、易混譯語統一規則

| 原文／問題 | 統一處理 |
| --- | --- |
| `Indikation` | 一律以「指標事由」為核心譯語；複合詞如 `Indikationstatbestand` 譯「指標事由構成要件」。 |
| `Schwangerschaftsabbruch` vs. `Abtreibung` | 前者原則「終止妊娠」；後者依語境「墮胎」。 |
| `Mißbilligung` | 「否定評價」；`rechtliche Mißbilligung` 為「法律否定評價」。 |
| `Vorwurf / vorwerfbar` | 可譯「非難／可非難」，不要機械併入 `Mißbilligung`。 |
| `Land / Länder / Landesregierung` | 「邦／各邦／邦政府」，不用「州」。 |
| `Zustimmung des Bundesrates` | 「聯邦參議院同意」，不是一般「通過」。 |
| `nicht rechtswidrig` | 「不具違法性」，除非文意明確，不簡化為「合法」。 |
| `straffrei` | 「不罰／不受刑罰處罰」，不等於「合法」。 |
| `Tatbestandsausschluss` | 「構成要件排除」，是案二理解「違法但不罰」的關鍵。 |
| `Rechtfertigungsgrund` | 「正當化事由」，會產生法秩序上許可效果。 |
| `Zumutbarkeit / Unzumutbarkeit` | 「可期待性／不可期待性」，不用「合理性」概括。 |
| `Rechtsgut` | 「法益」，不用「合法資產」。 |
| `Täter` | 「行為人」，不用「肇事者」。 |
| `Dunkelziffer` | 「黑數」。 |
| `Fehlschluß / Fehlschluss` | 「錯誤推論」。 |
